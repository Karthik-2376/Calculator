# Calculator Web App

This is a simple and responsive Calculator Web Application built using HTML, CSS, and JavaScript.  
The calculator performs basic arithmetic operations and has a clean UI with smooth button effects.

Live Demo:  
https://karthik-2376.github.io/Calculator/

## Features
- Addition, Subtraction, Multiplication, Division
- Backspace button
- Clear (AC) button
- Responsive design
- Hover and click button effects
- Modern UI styling

## Technologies Used
- HTML
- CSS
- JavaScript
 
## How It Works
HTML is used for layout, CSS for styling, and JavaScript for performing calculations and handling button clicks.

## Purpose
This project was built to practice:
- DOM manipulation
- Event handling
- CSS styling
- Building UI projects
